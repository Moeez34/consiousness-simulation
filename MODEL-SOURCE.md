# Downloaded bee navigation model

`research/path-integration/` contains the downloaded source for **Central complex path integration model** from the InsectRobotics research project:

- Repository: https://github.com/InsectRobotics/path-integration
- Paper: Stone et al., *An anatomically constrained model for path integration in the bee brain* (2017)
- Downloaded on: 2026-08-27

This model is a published computational account of bee navigation: compass signals, optic flow and a home-vector memory. It is not a pre-trained neural network, a complete biological bee brain, or evidence of consciousness. BeeCX uses this model as the scientific reference for the controller and keeps the downloaded source separate for an explicit future direct port.
