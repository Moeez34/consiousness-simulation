# Local research dependencies

The InsectRobotics path-integration source is downloaded locally into `path-integration/` for study and future integration, but is intentionally not vendored in this repository.

Download it with:

```powershell
git clone https://github.com/InsectRobotics/path-integration.git research/path-integration
```

See `../MODEL-SOURCE.md` for the model’s scope and provenance.
