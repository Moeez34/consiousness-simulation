# BeeCX — Voxel Foraging Lab

An interactive browser prototype for a bee-inspired autonomous agent in a sunny Minecraft-style riverside voxel biome. Open `index.html` in a modern browser.

## What is modelled

- A voxel-like meadow with a hive, flowers, and hazards.
- A single bee that searches for flowers, accumulates nectar, and returns to the hive.
- A compact, biologically inspired controller with visual sensory state, a heading, and a home-vector memory.

This is **not** a consciousness upload. The scientific model source has been downloaded into `research/path-integration/`; see `MODEL-SOURCE.md` for its scope and provenance. The next milestone is a direct port of the research model, then connecting the agent to a Minecraft integration.
